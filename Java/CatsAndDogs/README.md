# Виртуальная собака и кошка

## Поставленная задача

Создать программу на языке `Java`, которая создаёт виртуальную собаку и кошку, вызывает функции их разговора и выводит всю информацию о животных в консоль.

## Описание программы

Программа написана в процедурном стиле. Все действия выполняются простыми функциями без параметров:

1. `createDog()` создаёт виртуальную собаку.
2. `createCat()` создаёт виртуальную кошку.
3. `dogSpeak()` выводит в консоль речь собаки.
4. `catSpeak()` выводит в консоль речь кошки.
5. `printPetInfo()` выводит всю информацию о созданных животных.

В функции `main()` по очереди вызываются все необходимые функции. Информация о животных выводится напрямую в консоль.
