# Изменение значений переменных

## Поставленная задача:

> Напишите программу на Java которая меняет значение двух переменных не используя третью переменную.

## Итог выполнения задания:
Была разработана программа на языке `Java` которая меняет значение двух **int** переменных, при этом не используя третью переменную. Это было достигнуто следующим алгоритмом:

```
1) a = a + b
2) b = a - b
3) a = a - b
```

***

### Алгоритм работы:
1. Сначала в переменной a, прибавляем a к b
2. После в переменной b, отнимаем a от b
3. И в конце в переменной a, от a отнимаем b
